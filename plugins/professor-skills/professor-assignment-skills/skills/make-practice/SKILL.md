# Make a practice session

Optimize the sequence of practice and instructor intervention. First choose
SKETCH, STANDARD, or ASSURANCE; an explicit depth wins and a complete practice
session defaults to STANDARD. Read the
[activity package contract](references/activity-design.md) before creating a
complete package.

## 1. Define the target performance

Recover the skill or concept students should perform by the end, what they can
already do, the available time, group format, tools, and likely misconceptions.
Include a brief diagnostic when readiness is uncertain.

## 2. Build the practice ladder

Use only as many stages as the session needs:

```text
diagnose
-> model or worked example
-> guided practice
-> partially completed problem
-> independent practice
-> method selection or transfer challenge
-> feedback and exit check
```

Fade support deliberately. Hints should unlock thinking without doing the
substantive work. Add optional extension tasks so fast finishers deepen rather
than merely repeat.

## 3. Produce two views

At SKETCH depth, produce only the requested exercise, hint sequence, exit check,
or outline. At STANDARD and ASSURANCE depth, produce two views and an
`activity.yaml` proposal when its required identifiers are known, as defined in
the shared contract.

The student worksheet contains goals, tasks, space or prompts for work,
available hints, collaboration expectations, and an exit task.

The professor guide contains timing, model solution or demonstration, staged
hints, observation cues, common errors, intervention decisions, grouping notes,
solutions, and an exit-check interpretation.

At ASSURANCE depth, make alignment, workload, accessibility, integrity, and
any variant-equivalence checks explicit. Stop at the design for approval when
the professor requested approval first.

## Rules

- Practice develops independent performance; it is not homework relabelled for
  classroom use.
- Feedback should occur during the work, not only after submission.
- Preserve productive struggle while preventing students from remaining stuck.
- Keep summative grading low-stakes or absent unless the professor specifies
  otherwise.
