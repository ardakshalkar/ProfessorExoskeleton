# Make homework

Create the smallest homework that produces useful evidence of learning. First
choose SKETCH, STANDARD, or ASSURANCE using
[the activity package contract](references/activity-design.md); an explicit
depth wins and a complete homework defaults to STANDARD.

## 1. Establish the purpose

Identify whether the homework should reinforce recent learning, interleave old
and new concepts, prepare for later work, or assess independent performance.
Recover outcomes, prior learning, expected effort, permitted resources, AI
policy, submission format, and stakes. Ask only when a missing choice would
materially change the work; otherwise label assumptions.

## 2. Choose the disciplinary archetype

Use the form that best elicits the evidence: problem set, proof or derivation,
programming, data analysis, case recommendation, source analysis, close reading,
structured writing, design artifact, language production, or authentic task.
Do not default every discipline to generic short-answer questions.

## 3. Build a deliberate progression

Use only the parts the purpose needs:

```text
retrieve -> routine application -> select a method -> analyze -> transfer
```

Mix prior and current concepts when useful. If differentiation is requested,
change scaffolding and cognitive demand explicitly. Equivalent variants must
preserve workload, evidence, and scoring.

## 4. Produce two views

At SKETCH depth, produce only the requested task, outline, rubric fragment, or
revision. At STANDARD and ASSURANCE depth, produce two views and an
`activity.yaml` proposal when its required identifiers are known, as defined in
the shared contract.

The student brief includes purpose, outcomes, estimated effort, tasks,
deliverables, permitted resources and AI policy, submission instructions,
evaluation criteria, and a short reflection when valuable.

The professor guide includes solutions or expected evidence, rubric or marking
notes, common errors, optional hints, estimated timings, variant notes, and how
the work prepares or diagnoses later learning.

At ASSURANCE depth, make alignment, workload, accessibility, integrity, and
variant-equivalence checks explicit. Stop at the design for approval when the
professor requested approval first.

## Rules

- Homework tests or develops independent performance; do not disguise a highly
  guided worksheet as homework.
- Do not reward arbitrary volume, cosmetic complexity, or commit counts.
- Use process evidence such as rationale, intermediate work, revision history,
  or reflection only when it serves learning or integrity.
- Keep answer keys and teaching notes out of the student artifact.
