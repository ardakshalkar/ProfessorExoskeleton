# Write student feedback

Read [the grading contract](../../references/grading-contract.md). Load only the
student or explicitly scoped batch and keep restricted data outside the course
repository.

Before presenting feedback as final, pipe evaluations to
`prof-assess summary --rubric RUBRIC.json`. Use only criteria with complete,
stamped professor decisions. If any criterion is pending, produce a clearly
labelled professor-review draft and do not state an official total.

For each student, write concise feedback that:

- names demonstrated strengths with evidence;
- explains the highest-impact improvement against the rubric;
- gives one or two feasible next actions;
- separates criterion feedback from administrative notes;
- uses respectful, direct language and no unsupported claims about effort,
  intent, authorship, personality, or ability.

Keep evidence excerpts short and do not expose internal confidence values,
model reasoning, other students' work, or cohort comparisons. Saving or sending
feedback requires the professor's explicit destination and instruction; this
skill only prepares the text.
