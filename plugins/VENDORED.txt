What in this directory is source, and what is a copy.

  dsh-sample/               SOURCE. Written here. Edit it here.

  dsh-ainar-course-model/   COPIES, taken on 2026-09-04 from
  dsh-professor-pane/       ..\ProfessorExoskeletonDHS\plugins\
  professor-skills/

Do not edit the copies. The chain above them is:

  ProfessorHarness  --python plugin/build.py --target dsh-->  dsh-ainar-course-model
  ProfessorSkills   --python -m exo setup------------------>  professor-skills
  ProfessorSkills/DataLayer  --python -m exo setup--------->  ..\datalayer

so a change made in a copy here is lost the next time anybody re-vendors, and
lost silently. Edit the upstream checkout and re-vendor.

dsh-professor-pane is hand-written in ProfessorExoskeletonDHS rather than
generated, so that one has a real home to edit: ..\ProfessorExoskeletonDHS.

One way this copy DIVERGES from what `exo setup` produces: setup deliberately
omits node_modules (see PROFESSOR_SKILLS_EXCLUDE in its setup.py), and these
copies were taken with a plain recursive copy, so professor-skills carries the
63 MB node/node_modules that had been installed in the source checkout. That is
why `pres` works here without the separate npm install its own README asks for —
and why professor-skills/SOURCE.txt's last paragraph is not true of this copy.
